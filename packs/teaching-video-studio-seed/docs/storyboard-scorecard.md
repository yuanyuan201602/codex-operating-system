# 分镜评分表

用于第 2 步验证：同一个知识点跑 3 次，每次按下表打分。每项 0 / 1 / 2 分。

- **0**：有明显错误或缺失，教师会直接重写
- **1**：基本可用，需要改几处
- **2**：可以直接给学生看

| # | 检查项 | 看什么 |
|---|---|---|
| 1 | 只讲一个核心概念 | 是否塞进第二个概念；术语是否当场解释 |
| 2 | 前置知识成立 | 是否使用了学生没学过的东西 |
| 3 | 案例适龄 | 例子是否贴近该年级；有没有成人化的背景 |
| 4 | 事实与示意分清 | 自拟案例是否标注；有无伪造的数据或真实经历 |
| 5 | 因果可由画面推出 | 结论是展示出来的，还是旁白宣布的 |
| 6 | 类比有边界 | 映射写清了吗；有没有越界扩展 |
| 7 | 一镜头一个可观察变化 | 每个镜头的 beats 是否聚焦 |
| 8 | 字幕可读 | 字数、停留时间、术语 |
| 9 | 易错点被处理 | `misconceptions` 是否在某个镜头里被正面回应 |
| 10 | 结尾可复述或可迁移 | 是否留下一句话原理或一个迁移问题 |

## 判定

- **通过**：总分 ≥ 16/20，且第 1、4、5、6 项没有 0 分。
- **返工**：任一关键项（1、4、5、6）为 0，或总分 < 16。
- 记录每次的总分、0 分项、教师修改了什么、花了多少分钟。阈值先用本表，跑完首轮基线后再调整。

## 记录模板

```text
知识点：      年级：      类别：      运行序号：
各项得分：1:_ 2:_ 3:_ 4:_ 5:_ 6:_ 7:_ 8:_ 9:_ 10:_   总分：__/20
教师改动：
人工分钟数：
结论：通过 / 返工
```
