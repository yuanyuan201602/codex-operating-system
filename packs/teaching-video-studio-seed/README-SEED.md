# 这是快照，不是最终位置

本目录是 `teaching-video-studio` 项目的源码快照，暂放在基础设施仓库里，原因是项目的独立 GitHub 仓库还没有创建（创建远端仓库需要用户确认）。

落地到桌面：

```bash
# Mac
bash packs/teaching-video-studio-seed/install-to-desktop.sh        # → ~/Desktop/teaching-video-studio
```

```powershell
# Windows
.\packs\teaching-video-studio-seed\install-to-desktop.ps1          # → 桌面\teaching-video-studio
```

落地后：创建独立仓库并推送，然后**从基础设施仓库删除本目录**，并把 `projects/teaching-video-studio.md` 补上仓库地址。
