## 已知局限

- 像素回归用 PNG 哈希，要求同机器、同版本渲染。换机器后要重新生成基准关键帧。
- 回归只覆盖每个镜头 10% / 50% / 90% 三个位置，不是完整播放。
- 示范课是手写的，只证明骨架可用，不证明 Codex 能生成合格镜头。
- 示范课在测试局改时被改过（s02 文案、s02 时长 20→28 秒），提交历史里可见。
