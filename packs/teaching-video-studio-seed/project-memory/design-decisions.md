# 设计决策

日期：2026-10-09。来源：项目设计报告的独立评审与后续设计讨论。

## 方向

先做 skill 包 + Remotion 工程模板 + 检查脚本，用 Codex CLI 直接驱动；网页界面最后做，且只调用同一组 `tvs` 命令。原因：真正的差异化在教学方法、镜头隔离契约和自动检查，不在界面或自建桥接层。

## 已定的决定

- 引擎只用 Remotion；HyperFrames、生成式视频镜头后置。
- 宿主用官方 Codex SDK（需要时再换 app-server）。app-server 的认证按官方文档不得用于商业或托管服务。
- 先文字后代码：分镜经教师确认后才 `scaffold`。
- 镜头目录隔离；`scene.json` 是镜头内容唯一来源；`manifest.json` 是时长唯一来源；`storyboard.json` 只记录审批。完整分镜视图由 `tvs storyboard` 现场生成，不入库（入库会形成派生副本，破坏改动范围校验）。
- 动画只用归一化进度，改时长不改代码。
- 版本用 git；候选版本是 worktree，接受 = fast-forward 合并，过期基准拒绝。
- 首期静音加字幕；manifest 预留 `audio.durationSource`，将来接 TTS 时可改为由旁白决定时长。
- 字体：用系统字体栈（PingFang SC → Noto Sans SC → 微软雅黑 → 文泉驿），不内置字体文件，避免许可问题。换机器后必须核对导出画面里的中文字形。

## 刻意不做

多引擎并存、专业时间线、自建版本库或任务队列、审批界面、账户体系、TTS、生成式视频。

## 许可备忘

- Remotion：个人或 3 人以内组织免费（含商用）；做自动化视频产品或嵌入 Player 要按渲染次数付费。首期自用不涉及，商业化前必须重新核对（2026-10-09 核对自官方定价页）。
- 风格参考 mg-styles-15 为 MIT，仅限其作者自制部分。
- 本项目风格 token 与组件为自写，没有拷贝第三方素材。
