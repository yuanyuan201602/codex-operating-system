# 战役地图视频工作流

把史料、地理数据和视觉设计组织成可修改、可追溯的地图视频。已验证案例是斯摩棱斯克 1941 的 78 秒横屏片；迁移到其他战役的方法尚未通过第二个完整项目验证。

## 使用入口

- 完整制作、接手续作或整理研究：阅读 [完整制作流程](references/production-workflow.md)，只执行当前请求涉及的阶段。
- 继续斯摩棱斯克，或复用其 Canvas 渲染链路：再阅读 [案例与复现说明](references/smolensk-runbook.md)。其中路径、帧号、时间、地名和检查条件均为案例参数。
- 已有项目的小改动：先读当前交接和实现，定位受影响阶段；不要重新做全部调研、引入新框架或重新索取已确认偏好。

开始时用现有文件确定实际项目、当前版本、交付入口和参考材料。用户已经给出的画幅、视觉方向和阶段批准继续有效。斯摩棱斯克采用 1920×1080 / 16:9 / 30 fps；新项目根据目标和参考确认规格，不把这个案例规格视为所有地图视频的要求。

## 必须保留的制作边界

1. **史料和画面分开。** 明确亲自查阅、二手转引、相互冲突和未核实。战线插值是示意动画，不能声称是每天实测；期初兵力、阶段俘虏与全役伤亡不能混成实时计数。
2. **地理位置和标签分开。** 城市与部队由经纬度驱动；只移动文字、引线或镜头，不能用排版避让改写位置。地理数据本身有错时，依据来源另行修正并记录。
3. **参考证据与匹配范围一致。** 截图支持构图、配色和信息层级比较，不支持对完整运动、剪辑和声音的复刻声明。
4. **优先复用实际工程。** 不因为参考或技能名称就迁移框架。动画应能按指定帧重现；随机装饰固定种子，任意定位与连续播放应一致。
5. **技术检查与叙事检查并行。** 除遮挡、越界和跳动外，检查“讲到的地点能否看见、出口何时关闭、标注指向哪里”。编号部队旗与装饰性阵营旗含义要清楚。
6. **检查最终编码文件。** 回看关键帧与转场，听开头和结尾，核对口播、日期和战线，测试实际播放器的播放与定位。渲染成功不等于观感达标。

短样片是降低返工成本的技术步骤；除非用户设置了阶段批准点，不把每次检查变成人工审批。新题材资料缺失时，可继续整理已知地理、叙事和参考；依赖未知史实的镜头保留空缺或缩小范围，不能补造。工作流不授予发布、外发、付费、上传素材、切换模型或委派权限。

## 可复制的任务描述

> 使用 $battle-map-video，为【战役与时间范围】制作地图解说视频。项目目录是【路径】，参考材料是【链接或文件】，目标为【画幅、时长和受众】。先检查已有工程、资料和参考，再在本次授权范围内完成制作。保持史料和地理位置可追溯，用关键片段验证观感，交付可播放的成片与可继续修改的源文件。
